# Aroma Café

Menu digital 3D et système de commande à table pour Aroma Café (coffee house).

## Contenu

- `menu/` : menu mobile avec un produit en 3D par catégorie (Three.js, GSAP)
- `backend/` : serveur Spring Boot pour les commandes à table (à venir)

## Lancer le menu

Ouvrir `menu/index.html` avec l'extension Live Server de VS Code.
